# 🛡️ MV Chrome Security Extension

My first Chrome Extension for Cybersecurity Learning!

## What it does
- ✅ Blocks known malicious / phishing sites
- ✅ Shows Security Guard popup
- ✅ Scan button to check current page safety
- ✅ Protects you while browsing

## Features
- Blocks: phishing-test.com, malware-test.com, dangerous-site.com
- Real-time console protection log
- Beautiful alert page for blocked sites

## How to Install
1. Download this repo as ZIP
2. Open Chrome -> chrome://extensions/
3. Enable Developer Mode
4. Click Load unpacked -> Select folder
5. Pin the 🛡️ icon!
